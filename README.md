# film-qa

QA and Continuity Bot repo — Script Supervisor / Lore Keeper for Maxi Universe / Reev Cannon.

## Layout
- `lore/` — master lore bible and version history
- `reviews/` — episode QA reports with deviation logs
- `approvals/` — pass/fail sign-off per episode
- `continuity/` — scene-by-scene continuity notes
- `flags/` — open issues awaiting Showrunner resolution
- `references/` — style guides, palettes, character sheets
- `logs/` — daily QA activity and error patterns

Shared: `/workspace/film/qa/lore/`, `/workspace/film/qa/reviews/`, `/workspace/film/qa/approvals/`, `/workspace/film/master/`

Hard breaks = BLOCKING. Soft suggestions = NON-BLOCKING. Never rewrite creative — flag and recommend.
